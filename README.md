# Network-ATC

Радар для диспетчеров сети виртуальной авиации **SkyNetwork**. Работает как EuroScope, выглядит как нечто среднее между EuroScope и Aurora (IVAO). Глубокая настройка, своя система плагинов, свой формат секторов `.natc` и поддержка секторов EuroScope. Написан на C# (.NET 8, WPF).

## Возможности

**Запуск и сектора**
- При запуске открывается окно выбора сектора: недавние секторы, «Сектор Network-ATC… (.natc)», «Сектор EuroScope… (.sct)» и демо-сектор. Окно можно отключить, тогда сразу откроется последний сектор. Позже оно вызывается кнопкой **СЕКТОР** или `Ctrl+O`.
- Родной формат `.natc` (JSON) и секторы EuroScope `.sct`/`.ese` открываются одинаково. Любой открытый сектор можно экспортировать в `.natc` из окна выбора.

**Интерфейс в духе EuroScope**
- Весь экран — радар. Сверху компактная текстовая панель меню (СЕКТОР · КАРТЫ · СПИСКИ · НАСТРОЙКИ · подключение, сектор, масштаб, UTC), снизу командная строка с ASEL — выбранным бортом.
- Списки — плавающие окна поверх радара: **Вылет**, **Прилёт**, **Весь трафик**, **План полёта**, **Диспетчеры**, **Конфликты (STCA)**, **Сообщения**. Окна перетаскиваются за заголовок, меняют размер за угол и закрываются ✕. Положение и размер каждого окна сохраняются в профиле. Меню «СПИСКИ ▾» включает окна и расставляет их по умолчанию.
- Списки вылета и прилёта строятся по активным аэродромам (`.airport UUEE UUDD` или в настройках). Вылет показывает статус: стоянка, руление, разбег, взлёт. Прилёт показывает дальность и расчётное время. Окно конфликтов открывается само при срабатывании STCA.
- Новая тема по умолчанию «SkyNetwork»: сине-серый радар, тёмные панели, голубой акцент и жёлтый выбранный борт.

**Радар**
- Карта из секторов Network-ATC `.natc` и EuroScope `.sct`/`.ese`: границы, SID/STAR, трассы, GEO, регионы, ВПП, аэродромы, VOR/NDB/точки, подписи, линии секторов. Каждый слой включается отдельно.
- Цели с историей, линией прогноза и символами: ◇ без сопровождения, ■ на сопровождении, • на земле. IDENT, аварийные коды 7500/7600/7700.
- Настраиваемые теги с выносной линией: перетаскиваются мышью, средняя кнопка возвращает тег на место. Для выбранного и наведённого борта показывается подробный тег.
- STCA: текущие и прогнозируемые конфликты на 2 минуты вперёд, с настраиваемыми минимумами.
- Масштаб колесом к курсору, перемещение мышью, кольца дальности, масштабная линейка, координаты курсора.

**Интерактивный формуляр**
- Щелчок по полю тега открывает редактор прямо у борта:
  - позывной — сопровождать / отпустить, правый щелчок — меню борта;
  - эшелон или CFL — список эшелонов вокруг текущего (прокрутка колесом) и ручной ввод;
  - курс, скорость — списки значений и ручной ввод;
  - код — выдать свободный или ввести свой;
  - заметка — редактируется на месте;
  - тип, аэродромы — открыть план полёта.
- Поле под курсором подсвечивается. Щелчок отличается от перетаскивания тега по сдвигу мыши.
- Для каждого поля можно выбрать, что делают левый и правый щелчок: «Настройки → Теги → Щелчки по полям». Плагины могут делать свои поля кликабельными.

**Работа диспетчера**
- Подключение к FSD-серверу SkyNetwork (репозиторий `Skynetwork-fsd`): позиция, частота, дальность видимости. Позицию можно выбрать из `[POSITIONS]` сектора.
- Карточка борта с планом полёта и указаниями (CFL, курс, скорость, код, заметка), список ATC онлайн.
- Сообщения: на частоту, личные вкладки, сообщения сервера. Командная строка в стиле EuroScope.
- `.demo` запускает демо-трафик без сервера, чтобы сразу попробовать радар.

**Настройка**
- 5 готовых тем: SkyNetwork, Midnight, Graphite, Scope Green, Daylight. Можно изменить любой из ~40 цветов, импортировать и экспортировать тему в JSON.
- Три шаблона тегов (без сопровождения, на сопровождении, подробный) с живым предпросмотром. Плагины могут добавлять свои поля.
- Шрифты и размер тегов, масштаб и шрифт интерфейса, расположение окон списков.
- Фильтр высот, прогноз, число точек истории, размер символов, кольца дальности, эшелон перехода.
- Горячие клавиши для каждого действия и алиасы (`.ctc = contact $1 on $2`).
- Всё хранится в профиле `%APPDATA%\Network-ATC\profiles\default.json`.

## Команды

| Команда | Действие |
|---|---|
| `текст` | сообщение на основную частоту |
| `.cfl 350` / `.cfl A045` | разрешённый эшелон/высота выбранного борта |
| `.hdg 270`, `.spd 250` | назначенные курс и скорость (без числа — снять) |
| `.sq` / `.sq 4521` | выдать свободный код из диапазона профиля или указанный |
| `.scratch текст` | заметка к борту |
| `.track` / `.drop` | взять на сопровождение / отпустить |
| `.find AFL123` | найти и выделить борт |
| `.fp [AFL123]` | запросить план полёта |
| `.msg AFL123 текст` | личное сообщение |
| `.airport UUEE UUDD` | активные аэродромы для списков вылета и прилёта (без кодов — показать) |
| `.freq 118.100`, `.range 150` | основная частота и дальность видимости |
| `.demo` | демо-трафик |
| `.plugins`, `.help` | команды плагинов, справка |

Горячие клавиши по умолчанию: `+`/`−` масштаб, `Home` центр сектора, `.` командная строка, `F2` весь трафик, `F3` сообщения, `F4` план, `F5` вылет, `F6` карты, `F7` прилёт, `F8` сопровождать, `F9` конфликты, `F11` диспетчеры, `Ctrl+O` сектор, `Ctrl+K` подключение, `Ctrl+,` настройки, `Esc` снять выбор.

## Формат секторов Network-ATC (.natc)

Основной формат программы — JSON с расширением `.natc`. Его удобно писать и править вручную, генерировать скриптами и хранить в git. Карты не ограничены разделами EuroScope: каждая карта в `maps` — свой слой в меню «КАРТЫ» со своим цветом.

```json
{
  "format": "network-atc-sector",
  "version": 1,
  "info": { "name": "Москва", "defaultCallsign": "UUEE_DEL", "defaultAirport": "UUEE", "center": [55.97, 37.41], "magneticVariation": -11 },
  "colors": { "COLOR_SID": "#99CC66" },
  "vors": [{ "name": "SHR", "lat": 55.975, "lon": 37.425, "frequency": "114.600" }],
  "airports": [{ "name": "UUEE", "lat": 55.972778, "lon": 37.414722, "frequency": "131.500" }],
  "runways": [{ "airport": "UUEE", "id1": "06L", "id2": "24R", "heading1": 62, "heading2": 242, "end1": [55.96, 37.38], "end2": [55.98, 37.44] }],
  "maps": [
    { "name": "SID", "lines": [{ "name": "DEMO1A", "color": "#99CC66", "points": [[55.97, 37.41], [56.16, 37.16]] }] },
    { "name": "Зона ожидания DEMO5", "color": "#C08A3E", "lines": [{ "name": "HOLD", "points": [[56.41, 37.41], [56.46, 37.49], [56.43, 37.55]] }] }
  ],
  "positions": [{ "callsign": "UUEE_DEL", "radioName": "Sheremetyevo Delivery", "frequency": "129.800", "identifier": "ED", "prefix": "UUEE", "suffix": "DEL" }]
}
```

Также есть `ndbs`, `fixes`, `regions`, `labels`, `freeTexts`, `sectorLines` и `sectors` (воздушное пространство). Полный пример — `demo/UUEE-demo.natc`. Карты с именами `GEO`, `SID`, `STAR`, `LOW AIRWAY`, `HIGH AIRWAY`, `ARTCC`, `ARTCC HIGH`, `ARTCC LOW` попадают в стандартные слои, остальные становятся отдельными слоями.

## Сектора EuroScope

Откройте `.sct` в окне выбора сектора. Если рядом лежит `.ese` с тем же именем, он загрузится автоматически. Поддерживаются:

- `.sct`: `#define`-цвета, `[INFO]`, `[VOR]`, `[NDB]`, `[AIRPORT]`, `[RUNWAY]`, `[FIXES]`, `[ARTCC]`, `[ARTCC HIGH]`, `[ARTCC LOW]`, `[SID]`, `[STAR]`, `[LOW AIRWAY]`, `[HIGH AIRWAY]`, `[GEO]`, `[REGIONS]`, `[LABELS]`. Координаты можно задавать и именами точек.
- `.ese`: `[POSITIONS]`, `[FREETEXT]`, `[AIRSPACE]` (линии и секторы).

Цвета карты берутся из темы. В настройках можно переключиться на цвета из файла сектора. Для проверки в комплекте есть учебный сектор в обоих форматах: `demo/UUEE-demo.sct` и `demo/UUEE-demo.natc`.

## Плагины

Свой API плагинов: .NET 8, сборка `NetworkAtc.PluginApi`. Плагин может:
- добавлять поля тегов и команды;
- рисовать поверх радара;
- добавлять пункты в меню борта;
- подсвечивать борты;
- читать трафик, планы полёта и сообщения;
- отправлять сообщения.

Пример — `examples/SamplePlugin`, руководство — [docs/plugins.md](docs/plugins.md). DLL плагинов кладутся в `%APPDATA%\Network-ATC\plugins`.

**Плагины EuroScope не загружаются.** Это нативные C++ DLL, собранные под закрытый API EuroScope (`EuroScopePlugIn.h`), исходного кода EuroScope в открытом доступе нет. Network-ATC распознаёт такие файлы и пишет, что они не поддерживаются. Совместимость с EuroScope — по данным: сектора `.sct`/`.ese`. Функции популярных плагинов лучше переносить на API Network-ATC.

## Сборка

Нужны Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download).

```powershell
dotnet build NetworkAtc.sln -c Release
dotnet run --project src/NetworkAtc.App -c Release
```

Готовая сборка (self-contained, .NET не нужен) — в [Actions → Release](../../actions/workflows/release.yml), архив в разделе *Artifacts*. Теги `v*` публикуются в *Releases*.

## Структура

| Проект | Назначение |
|---|---|
| `src/NetworkAtc.PluginApi` | API для плагинов: единственная сборка, на которую ссылается плагин |
| `src/NetworkAtc.Core` | Протокол FSD, сессия диспетчера, треки, STCA, сектора, теги, профили, плагины, команды |
| `src/NetworkAtc.App` | Интерфейс WPF и отрисовка радара |
| `examples/SamplePlugin` | Пример плагина |
| `tests/NetworkAtc.Core.Tests` | Тесты ядра, в том числе сквозной тест с настоящим FSD-сервером |
