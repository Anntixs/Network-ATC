# Network-ATC

Радар для диспетчеров сети виртуальной авиации **SkyNetwork**. Работает как EuroScope, выглядит как нечто среднее между EuroScope и Aurora (IVAO). Глубокая настройка, своя система плагинов, свой формат секторов `.natc` и поддержка секторов EuroScope. Написан на C# (.NET 8, WPF).

## Возможности

**Запуск и сектора**
- При запуске открывается окно выбора сектора: недавние секторы, «Сектор Network-ATC… (.natc)», «Сектор EuroScope… (.sct)» и демо-сектор. Окно можно отключить, тогда сразу откроется последний сектор. Позже оно вызывается кнопкой **СЕКТОР** или `Ctrl+O`.
- Родной формат `.natc` (JSON) и секторы EuroScope `.sct`/`.ese` открываются одинаково. Любой открытый сектор можно экспортировать в `.natc` из окна выбора.

**Интерфейс в духе EuroScope**
- Весь экран — радар. Сверху компактная текстовая панель меню (СЕКТОР · КАРТЫ · СПИСКИ · ВПП · РАДИО · НАСТРОЙКИ · подключение, сектор, масштаб, UTC), снизу командная строка с ASEL — выбранным бортом.
- Списки — плавающие окна поверх радара: **Вылет**, **Прилёт**, **Весь трафик**, **План полёта**, **Диспетчеры**, **Конфликты (STCA)**, **Сообщения**. Окна перетаскиваются за заголовок, меняют размер за угол и закрываются ✕. Положение и размер каждого окна сохраняются в профиле. Меню «СПИСКИ ▾» включает окна и расставляет их по умолчанию.
- Списки вылета и прилёта строятся по активным аэродромам (`.airport UUEE UUDD` или в настройках). Вылет показывает статус: стоянка, руление, разбег, взлёт. Прилёт показывает дальность и расчётное время. Окно конфликтов открывается само при срабатывании STCA.
- Новая тема по умолчанию «SkyNetwork»: сине-серый радар, тёмные панели, голубой акцент и жёлтый выбранный борт.

**Функции EuroScope**
- **Передача бортов между диспетчерами.** Можно взять борт, отпустить его, передать другому диспетчеру (принять или отклонить входящую передачу, отменить свою) и показать борт соседу (point-out). Протокол тот же, что у EuroScope: `$HO`/`$HA`, `#PC … CCP`, общие данные `$CQ … @94835`. Сервер SkyNetwork передаёт их всем диспетчерам.
- **Общие указания.** CFL, курс, скорость, код, заметка, SID/STAR, ВПП, флаг «разрешение получено» и наземный статус видят все диспетчеры. Новый диспетчер спрашивает, у кого борт, и владелец присылает ему всё, что назначил.
- **Состояния тега, как в EuroScope:**
  - «не касается», «касается» (входит в ваш сектор или летит с ваших аэродромов);
  - «на сопровождении»;
  - «передают мне» (мигает), «передаю»;
  - «у другого диспетчера».

  У каждого состояния свой цвет в теме.
- **Секторы и следующий диспетчер.** Из `[AIRSPACE]` в `.ese` строятся границы секторов. Владелец сектора — первая позиция из OWNER, которая сейчас в сети. Программа определяет, в чей сектор борт войдёт дальше. Это поле `{next}` тега, передача одним нажатием (`Ctrl+H`, `.ho`) и списки SIL/SEL.
- **SID и STAR.** Берутся из `[SIDSSTARS]` в `.ese` (в `.natc` — массив `procedures`). Процедура подбирается автоматически по активной ВПП и маршруту: SID — по последней точке, STAR — по первой. Её можно назначить вручную из тега, меню борта, плана полёта или командами `.sid`/`.star`.
- **Окно «ВПП»** (`Ctrl+R`) — активные аэродромы, ВПП вылета и посадки, буква ATIS. У ВПП посадки рисуется продолжение оси на 15 NM с отметками через 5 NM.
- **Списки:**
  - вылет — SID, ВПП, код, флаг CLR (щелчком), статус;
  - прилёт — STAR, ВПП, эшелон, дальность, ETA;
  - **SIL** — входящие: кого передают и кто войдёт в ваш сектор, со временем до входа; двойной щелчок — принять;
  - **SEL** — выходящие: ваши борта и следующий диспетчер; двойной щелчок — передать.
- **Предупреждения в теге:**
  - **CLAM** — борт отклонился от разрешённой высоты и не возвращается к ней;
  - **DUPE** — у двух бортов одинаковый код;
  - **SQ** — борт выставил не тот код, что ему назначен;
  - аварийные коды.
- **Коды ответчика** выдаются из диапазона вашей позиции в `.ese` (поля 10–11 `[POSITIONS]`), а если его нет — из диапазона профиля.
- **Изменение плана полёта.** В окне плана редактируются правила, тип, TAS, аэродромы, RFL, время вылета, маршрут и примечания. Кнопка «Отправить изменения» отправляет `$AM`.
- **METAR и ATIS.** Сверху показывается строка погоды активных аэродромов: буква ATIS, ветер, QNH; METAR загружается с aviationweather.gov. Пилотам по запросу уходит информация о диспетчере (`$CR … ATIS`); её текст задаётся в настройках, переменные в нём работают.
- **Инструменты радара:**
  - протяжка правой кнопкой — линия расстояния и пеленга. Если провести её между двумя бортами, показывается минимальное сближение и через сколько минут оно будет. `Esc` убирает линии;
  - маршрут борта на карте, через точки SID и STAR;
  - кольцо вокруг борта на 1–15 NM;
  - `.sep` — расчёт сближения двух бортов командой.
- **Меню борта (правая кнопка)** устроено как в EuroScope: передача, point-out, SID, STAR, ВПП, CLR, наземный статус, код, маршрут, кольцо, «выйти на мою частоту», личное сообщение.
- **Звуки событий:** сообщения, передача борта, point-out, STCA, подключение. Тоны синтезируются программой, аудиофайлы не нужны. Каждый звук включается отдельно в настройках.
- **Переменные в алиасах, как в EuroScope:** `$aircraft`, `$cfl`, `$sid`, `$deprwy`, `$myfreq`, `$metar(UUEE)`, `$wind(UUEE)`, `$qnh(UUEE)`, `$atiscode(UUEE)` и другие.
- **Тема «EuroScope Classic»** для тех, кому нужны привычные цвета.

**Радар**
- Карта из секторов Network-ATC `.natc` и EuroScope `.sct`/`.ese`: границы, SID/STAR, трассы, GEO, регионы, ВПП, аэродромы, VOR/NDB/точки, подписи, линии секторов. Каждый слой включается отдельно.
- Цели с историей, линией прогноза и символами: ◇ без сопровождения, ■ на сопровождении, • на земле. IDENT, аварийные коды 7500/7600/7700.
- Настраиваемые теги с выносной линией: перетаскиваются мышью, средняя кнопка возвращает тег на место. Для выбранного и наведённого борта показывается подробный тег.
- STCA: текущие и прогнозируемые конфликты на 2 минуты вперёд, с настраиваемыми минимумами.
- Масштаб колесом к курсору, перемещение мышью, кольца дальности, масштабная линейка, координаты курсора.

**Интерактивный формуляр**
- Щелчок по полю тега открывает редактор прямо у борта:
  - позывной — сопровождать / отпустить, правый щелчок — меню борта;
  - эшелон или CFL — список эшелонов вокруг текущего (прокрутка колесом) и ручной ввод;
  - курс, скорость — списки значений и ручной ввод;
  - код — выдать свободный или ввести свой;
  - заметка — редактируется на месте;
  - тип, аэродромы — открыть план полёта.
- Поле под курсором подсвечивается. Щелчок отличается от перетаскивания тега по сдвигу мыши.
- Для каждого поля можно выбрать, что делают левый и правый щелчок: «Настройки → Теги → Щелчки по полям». Плагины могут делать свои поля кликабельными.

**Работа диспетчера**
- Подключение к FSD-серверу SkyNetwork (репозиторий `Skynetwork-fsd`): позиция, частота, дальность видимости. Позицию можно выбрать из `[POSITIONS]` сектора. Для передачи бортов и общих указаний нужна версия сервера, которая пересылает `$CQ … @94835` всем диспетчерам.
- Карточка борта с планом полёта и указаниями (CFL, курс, скорость, код, заметка), список ATC онлайн.
- Сообщения: на частоту, личные вкладки, сообщения сервера. Командная строка в стиле EuroScope.
- `.demo` запускает демо-трафик без сервера, чтобы сразу попробовать радар.

**Настройка**
- 5 готовых тем: SkyNetwork, Midnight, Graphite, Scope Green, Daylight. Можно изменить любой из ~40 цветов, импортировать и экспортировать тему в JSON.
- Три шаблона тегов (без сопровождения, на сопровождении, подробный) с живым предпросмотром. Плагины могут добавлять свои поля.
- Шрифты и размер тегов, масштаб и шрифт интерфейса, расположение окон списков.
- Фильтр высот, прогноз, число точек истории, размер символов, кольца дальности, эшелон перехода.
- Горячие клавиши для каждого действия и алиасы (`.ctc = contact $1 on $2`).
- Всё хранится в профиле `%APPDATA%\Network-ATC\profiles\default.json`.

## Голосовая связь

Network-ATC — ещё и радиостанция диспетчера: голос идёт через голосовой сервер SkyNetwork.

- **Подключение.** Голос подключается сам, когда удалось подключиться к сети, и отключается вместе с ней. Используются те же CID, пароль и позывной; хост тот же, что у FSD-сервера, порт по умолчанию `3782`. Диспетчер на позиции говорит и слушает. Наблюдатель (OBS) только слушает: основную частоту, если она задана, и дополнительные. Если голосовой сервер недоступен, работа в сети продолжается. Ошибка показывается в окне сообщений, раз в 30 с программа пробует подключиться снова. Переподключиться сразу можно кнопкой в окне **РАДИО**.
- **Окно «Голосовая связь»** (кнопка **РАДИО** в меню, точка на ней показывает состояние):
  - основная частота из подключения и до 7 дополнительных; у каждой RX (приём), TX (передача) и громкость;
  - тангента — клавиша, кнопка мыши (кроме левой и правой) или кнопка джойстика: «Назначить…» и нажмите нужную;
  - микрофон, динамики, усиление микрофона с индикатором уровня, громкость приёма;
  - порт голосового сервера и выключатель «Подключать голосовую связь вместе с сетью».
- **Антенны** стоят в центре видимости диспетчера на высоте 100 ft. Если центр неизвестен, используется первый активный аэродром или центр сектора.
- **Индикация.** Внизу справа строка `RX 118.100 AFL123` показывает, кого сейчас слышно; борт, который говорит, обведён на радаре кольцом. Частота `TX …` краснеет, пока вы в эфире. Кнопку **PTT** рядом можно держать мышью вместо тангенты.
- **Тангента и горячие клавиши.** Тангента работает, даже когда окно не в фокусе. Если та же клавиша назначена на команду программы, команда по ней не выполняется, и окно РАДИО об этом предупреждает. В полях ввода буквенная тангента печатает символ и одновременно включает передачу, поэтому лучше выбрать клавишу, которая не печатает: правый Ctrl, Caps Lock, кнопку мыши 4/5 или джойстик.
- Частоты, устройства, громкость и тангента хранятся в профиле (раздел `Voice`).

## Команды

| Команда | Действие |
|---|---|
| `текст` | сообщение на основную частоту |
| `.cfl 350` / `.cfl A045` | разрешённый эшелон/высота выбранного борта |
| `.hdg 270`, `.spd 250` | назначенные курс и скорость (без числа — снять) |
| `.sq` / `.sq 4521` | выдать свободный код из диапазона позиции (или профиля) или указанный |
| `.scratch текст` | заметка к борту |
| `.assume` / `.release` (`.track` / `.drop`) | взять борт (или принять передачу) / отпустить |
| `.ho [UUEE_APP \| EA]` | передать борт; без позиции — следующему диспетчеру по сектору |
| `.accept` / `.refuse` / `.hc` | принять / отклонить передачу / отменить свою |
| `.po UUWV_CTR` | показать борт другому диспетчеру (point-out) |
| `.sid [DEMO1A]`, `.star [DEMO2A]` | назначить SID/STAR (без имени — автоматически) |
| `.drwy 24R`, `.arwy 24L` | ВПП вылета/посадки выбранного борта |
| `.rwy UUEE 24R [24L]` | активные ВПП аэродрома: вылет [посадка] |
| `.clr`, `.state PUSH` | флаг «разрешение получено», наземный статус (STUP/PUSH/TAXI/DEPA) |
| `.route`, `.halo 5` | маршрут на радаре, кольцо вокруг борта |
| `.sep AFL1 SBI2` | расстояние, пеленг и минимальное сближение |
| `.atis UUEE B` / `.atis UUEE +` | буква ATIS |
| `.metar [UUEE]` | METAR |
| `.contactme`, `.wallop текст`, `.info` | «выйдите на мою частоту», запрос супервизору, информация о диспетчере |
| `.find AFL123` | найти и выделить борт |
| `.fp [AFL123]` | запросить план полёта |
| `.msg AFL123 текст` | личное сообщение |
| `.airport UUEE UUDD` | активные аэродромы для списков вылета и прилёта (без кодов — показать) |
| `.freq 118.100`, `.range 150` | основная частота и дальность видимости |
| `.demo` | демо-трафик |
| `.plugins`, `.help` | команды плагинов, справка |

Горячие клавиши по умолчанию: `+`/`−` масштаб, `Home` центр сектора, `.` командная строка, `F2` весь трафик, `F3` сообщения, `F4` план, `F5` вылет, `F6` карты, `F7` прилёт, `F8` сопровождать, `F9` конфликты, `F11` диспетчеры, `Ctrl+O` сектор, `Ctrl+K` подключение, `Ctrl+,` настройки, `F12` взять борт / принять передачу, `Ctrl+H` передать следующему, `Ctrl+D` отпустить / отклонить, `Ctrl+T` маршрут, `Ctrl+R` ВПП, `Ctrl+I` SIL, `Ctrl+E` SEL, `Esc` снять выбор (второй раз — убрать линии измерений).

## Формат секторов Network-ATC (.natc)

Основной формат программы — JSON с расширением `.natc`. Его удобно писать и править вручную, генерировать скриптами и хранить в git. Карты не ограничены разделами EuroScope: каждая карта в `maps` — свой слой в меню «КАРТЫ» со своим цветом.

```json
{
  "format": "network-atc-sector",
  "version": 1,
  "info": { "name": "Москва", "defaultCallsign": "UUEE_DEL", "defaultAirport": "UUEE", "center": [55.97, 37.41], "magneticVariation": -11 },
  "colors": { "COLOR_SID": "#99CC66" },
  "vors": [{ "name": "SHR", "lat": 55.975, "lon": 37.425, "frequency": "114.600" }],
  "airports": [{ "name": "UUEE", "lat": 55.972778, "lon": 37.414722, "frequency": "131.500" }],
  "runways": [{ "airport": "UUEE", "id1": "06L", "id2": "24R", "heading1": 62, "heading2": 242, "end1": [55.96, 37.38], "end2": [55.98, 37.44] }],
  "maps": [
    { "name": "SID", "lines": [{ "name": "DEMO1A", "color": "#99CC66", "points": [[55.97, 37.41], [56.16, 37.16]] }] },
    { "name": "Зона ожидания DEMO5", "color": "#C08A3E", "lines": [{ "name": "HOLD", "points": [[56.41, 37.41], [56.46, 37.49], [56.43, 37.55]] }] }
  ],
  "positions": [{ "callsign": "UUEE_DEL", "radioName": "Sheremetyevo Delivery", "frequency": "129.800", "identifier": "ED", "prefix": "UUEE", "suffix": "DEL" }]
}
```

Также есть `ndbs`, `fixes`, `regions`, `labels`, `freeTexts`, `sectorLines`, `sectors` (воздушное пространство и владельцы) и `procedures` — SID/STAR: `{ "kind": "SID", "airport": "UUEE", "runway": "24R", "name": "DEMO1A", "route": ["SHR", "DEMO5"] }`. У позиции можно задать диапазон кодов: `"squawks": [4201, 4277]`. Полный пример — `demo/UUEE-demo.natc`. Карты с именами `GEO`, `SID`, `STAR`, `LOW AIRWAY`, `HIGH AIRWAY`, `ARTCC`, `ARTCC HIGH`, `ARTCC LOW` попадают в стандартные слои, остальные становятся отдельными слоями.

## Сектора EuroScope

Откройте `.sct` в окне выбора сектора. Если рядом лежит `.ese` с тем же именем, он загрузится автоматически. Поддерживаются:

- `.sct`: `#define`-цвета, `[INFO]`, `[VOR]`, `[NDB]`, `[AIRPORT]`, `[RUNWAY]`, `[FIXES]`, `[ARTCC]`, `[ARTCC HIGH]`, `[ARTCC LOW]`, `[SID]`, `[STAR]`, `[LOW AIRWAY]`, `[HIGH AIRWAY]`, `[GEO]`, `[REGIONS]`, `[LABELS]`. Координаты можно задавать и именами точек.
- `.ese`: `[POSITIONS]` (с диапазонами кодов), `[FREETEXT]`, `[SIDSSTARS]`, `[AIRSPACE]` (линии, секторы, владельцы).

Цвета карты берутся из темы. В настройках можно переключиться на цвета из файла сектора. Для проверки в комплекте есть учебный сектор в обоих форматах: `demo/UUEE-demo.sct` и `demo/UUEE-demo.natc`.

## Плагины

Свой API плагинов: .NET 8, сборка `NetworkAtc.PluginApi`. Плагин может:
- добавлять поля тегов и команды;
- рисовать поверх радара;
- добавлять пункты в меню борта;
- подсвечивать борты;
- читать трафик, планы полёта и сообщения;
- отправлять сообщения.

Пример — `examples/SamplePlugin`, руководство — [docs/plugins.md](docs/plugins.md). DLL плагинов кладутся в `%APPDATA%\Network-ATC\plugins`.

**Плагины EuroScope не загружаются.** Это нативные C++ DLL, собранные под закрытый API EuroScope (`EuroScopePlugIn.h`), исходного кода EuroScope в открытом доступе нет. Network-ATC распознаёт такие файлы и пишет, что они не поддерживаются. Совместимость с EuroScope — по данным: сектора `.sct`/`.ese`. Функции популярных плагинов лучше переносить на API Network-ATC.

## Сборка

Нужны Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download).

```powershell
dotnet build NetworkAtc.sln -c Release
dotnet run --project src/NetworkAtc.App -c Release
```

## Структура

| Проект | Назначение |
|---|---|
| `src/NetworkAtc.PluginApi` | API для плагинов: единственная сборка, на которую ссылается плагин |
| `src/NetworkAtc.Core` | Протокол FSD, сессия диспетчера, треки, STCA, сектора, теги, профили, плагины, команды |
| `src/NetworkAtc.App` | Интерфейс WPF и отрисовка радара |
| `src/SkyNetwork.Voice` | Голосовая связь: протокол голосового сервера, Opus, радиоэффекты, микшер, тангента, аудиоустройства (общая библиотека SkyNetwork, копия) |
| `examples/SamplePlugin` | Пример плагина |
| `tests/NetworkAtc.Core.Tests` | Тесты ядра, в том числе сквозной тест с настоящим FSD-сервером |
